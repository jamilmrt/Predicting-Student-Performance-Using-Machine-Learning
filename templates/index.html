Predicting Student Performance using Machine Learning

This project endeavours to develop a machine learning model capable of predicting student performance in mathematics based on a range of factors, including gender, race/ethnicity, parental level of education, lunch type, test preparation course, and exam scores.

The model has been trained on a dataset of student information and their corresponding exam scores, and is capable of providing insights into the factors that influence student performance.

For further information, please refer to the GitHub repository, which contains the project codebase. Additionally, the Flask API is available for making predictions.
